Detailed Description

Dialect hook for materializing independent storage for mutable value types.

Implementations must recursively copy every mutable value child. Immutable scalar values and identity-bearing handles are handled by the common entry points below and do not require a dialect implementation.

virtual bool llzk::ValueCopyDialectInterface::canMaterializeValueCopy ( mlir::Type type) const
pure virtual

Return whether the value semantics of type can be preserved by either reusing the same SSA value or materializing independent mutable storage.

Returning false means that reuse would introduce observable aliasing and this interface cannot currently construct the required independent copy.
