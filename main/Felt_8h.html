◆ llzkFelt_FeltTypeGetFromRef()

MLIR_CAPI_EXPORTED MlirType llzkFelt_FeltTypeGetFromRef ( MlirContext ctx,
MlirStringRef fieldName )

Gets a llzk::felt::FeltType referring to an already defined field.

Requirements: fieldName must exactly match a built-in field name (e.g., "bn254") or a custom field registered with LLZK. Pass the name itself, without quotes or an '@' prefix. The string must contain fieldName.length readable bytes; it need not be null-terminated and is copied into ctx, so its storage need only remain valid for this call.

A fieldName that has not been defined emits a diagnostic and returns a null type. Use llzkFelt_FeltTypeGetUnspecified for an unspecified field, rather than an empty name here.
