enum class llzk::polymorphic::detail::flattening::ConsumerTypeCheck : std::uint8_t
strong

Strength of the independently declared type requirement.

In-place propagation must preserve exact concrete types (including affine specializations); scalar replacement can use unification. Refinement additionally recognizes specializations recorded by this pass.

Enumerator
Exact 

The consumer's declared type must match, even if it is still generic.

ConcreteExact 

Concrete declarations must match exactly; generic declarations may remain unresolved.

Refinement 

A concrete declaration may also be a specialization recorded by this pass.

Unification 

Index-specific replacements may unify with the consumer's declared type.
